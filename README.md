# Wuyue and the road of the sutras

A single-page map of how Buddhist texts travelled from India to the kingdom of Wuyue
(907–978), and on to Korea and Japan.

The site is one static file, `index.html`. It has no build step and no dependencies.
It loads Spectral and Noto Serif TC from Google Fonts. Everything else is inline.

Source: Claude artifact https://claude.ai/artifact/8RScD7bpSLN4SU2H9piNT9

## Run locally

```sh
npx serve .
```

## Deploy

Vercel serves `index.html` as a static site with no config: `vercel deploy`.
